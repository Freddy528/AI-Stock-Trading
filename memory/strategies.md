## 🏛️ 策略体系 (v0.2) — 2026-03-17

### 一、核心投资哲学（来自大师）

#### 1. 利弗莫尔 (Jesse Livermore) 交易法则
- **最小阻力原则**：等待"最小阻力方向"出现后顺势而为，不在随机波动中操作
- **关键点交易**：只在关键时刻（趋势转折点或突破点）入场
- **分批建仓**：先20%仓位试探，确认方向正确后分2-3次加仓；绝不逆势加仓
- **及时止损**：单次风险不超过总资金的2%，错了就走
- **耐心等待**：没有明确信号时，空仓等待
- **一日反转信号**：当日高点>前日高点，但收盘<前日收盘且放量→见顶
- ⚠️ 利弗莫尔三次破产均在震荡市，A股T+1下需更审慎

#### 2. 欧奈尔 CANSLIM 选股法
- **C** (Current Earnings): 最近季度EPS同比增长≥20%，越高越好(40-100%更佳)，关注"加速增长"
- **A** (Annual Earnings): 过去3年EPS连续增长，年增速≥25%；ROE>17%
- **N** (New): 新产品/新管理层/股价创新高（无套牢盘压力）
- **S** (Supply & Demand): 优选小流通盘，成交量放大确认
- **L** (Leader): 相对强弱RS≥80，只买行业前2-3名，不买落后股和同情股
- **I** (Institutional): 有业绩领先的机构（公募/外资）开始建仓
- **M** (Market Direction): 75%的股票跟随大盘，只在确认牛市时积极入场
- **止损铁律**：买入后下跌7-8%无条件止损
- **买入形态**：突破杯柄形态等底部整理形态时放量买入

#### 3. A股龙头战法要点
- 找到市场最强主线题材
- **二板定龙头**：首板不确定性高，二板时龙头身份得到市场确认，是较安全的介入时机
- **分歧转一致**：前一天大烂板（严重分歧），次日再次上板（一致看好）= 弱转强，确定性高
- **缩量调整后放量突破**：2-3波放量后缩量调整，第一个放量过前高涨停板是买点
- 龙头不再封板/炸板时卖出；新题材分流资金时卖出
- 持有两天未继续上涨则卖出（快进快出）
- ⚠️ 高风险策略：打板炸板次日可能亏20%，需极强纪律和盘感

#### 4. 缠论核心要点
- **基本概念层级**：分型 → 笔 → 线段 → 走势中枢 → 走势类型
- **走势终完美**：所有走势类型最终都会结束，关键是判断何时结束
- **三类买点**：
  - B1（第一类买点）：下跌趋势中出现底背离（最后一段下跌力度<前一段），趋势即将反转，最核心买点
  - B2（第二类买点）：B1后第一次回调不破前低，确认趋势已反转
  - B3（第三类买点）：中枢上沿突破后回踩不回到中枢内，确认趋势加速
- **三类卖点**：
  - S1：上涨趋势中出现顶背离
  - S2：S1后第一次反弹不破前高
  - S3：中枢下沿跌破后反弹不回到中枢内
- **适用**：所有级别（短线用5分钟/15分钟，波段用日线）
- ⚠️ 学习曲线极陡，实时判断中枢和背离非常困难，分型/笔划分有主观性

#### 5. A股T+1特殊风控
- 当日买入无法当日止损，买入前需更充分确认
- **尾盘买入策略**：14:50后买入可缩短持仓风险窗口
- 主力常利用T+1："今日封板吸引跟风，次日高开出货"

### 二、技术分析策略工具箱

#### 策略1：均线多头排列 + 放量突破（葛兰碧法则）
- **核心逻辑**：MA5 > MA10 > MA20 > MA60，股价放量突破前高
- **均线定义**：5日（攻击线）、10日（波段生命线）、20日（趋势线）、60日（生死线）、250日（牛熊分界线）
- **买入信号（葛兰碧四大买入法则）**：
  1. 均线由下降转走平/上升，股价从下方向上突破均线（金叉）
  2. 股价回调至均线附近获支撑后再度上涨（回踩不破）
  3. 股价短暂跌破上升中的均线后迅速收回
  4. 股价远离均线急跌后向均线回归（超跌反弹，不宜期望过高）
- **卖出信号（葛兰碧四大卖出法则）**：
  5. 股价远离均线急涨后向均线回归（乖离率过大）
  6. 均线由上升转走平/下降，股价从上方跌破均线（死叉）
  7. 股价反弹至下降中的均线附近遇阻回落
  8. 股价在均线上方急速拉升远离均线（短线获利回吐）
- **量能确认**：成交量 > 5日均量 × 1.5 为有效突破
- **适用**：趋势行情；5/10日均线适合短线，20/60日均线适合波段
- ⚠️ 简单双均线策略胜率仅约37%，但盈亏比可达3.65，适合趋势跟踪

#### 策略2：MACD 金叉 + KDJ 共振
- **核心逻辑**：多指标共振确认买卖点，降低单一指标误判率
- **买入信号**：
  - MACD 零轴上方金叉（DIF 上穿 DEA），零轴附近信号更强
  - KDJ 的 J 值从超卖区（<20）上穿 K、D
  - 成交量放大配合
  - 加分项：MACD底背离（股价新低但MACD不新低）
- **卖出信号**：
  - MACD 高位死叉（零轴下方死叉空头信号更强）
  - KDJ 的 J 值 > 90 后拐头向下
  - 加分项：MACD顶背离（股价新高但MACD不新高）
- **适用**：震荡和趋势行情
- ⚠️ KDJ在单边趋势中会钝化（持续超买/超卖），需结合MACD确认趋势方向

#### 策略3：量价关系分析 + 资金流入
- **核心逻辑**："量是因，价是果；量在先，价在后"
- **经典量价形态**：
  - **地量地价**：长期下跌后成交量极度萎缩（换手率<1%），卖盘枯竭 → 筑底信号
  - **缩量后温和放量上涨**：底部缩量整理后成交量温和递增 + 股价上涨 → 健康上攻
  - **量增价涨**：上涨趋势中量价齐升 → 多头主导，趋势可靠
  - **天量天价**：高位放出历史巨量且股价创新高 → 往往见顶
  - **高位放量滞涨**：大涨后放量但价格不再上行 → 主力出货概率大
  - **放量下跌**：高位区域放量下跌 → 获利盘涌出，强卖出信号
- **资金流向辅助（多维度验证）**：
  - 主力资金净流入为正 + 放量上涨 → 强买入信号
  - 主力资金连续2天净流出 → 卖出信号
  - 北向资金当日净买入 → 加分项
  - **个股资金流入看3个周期**：
    - 当日主力净流入 → 短线信号
    - 3日累计主力净流入 → 短期趋势确认
    - 5日累计主力净流入 → 中期建仓确认
  - **板块资金流入同样看多日**：
    - 当日板块资金净流入排名 → 短线热点
    - 3-5日板块累计净流入 → 持续性主线（比单日更可靠）
  - **北向资金也看连续性**：单日大进大出可能是调仓，连续3日同方向才有参考价值
- **适用**：所有行情阶段，量价关系是判断趋势真伪的核心工具
- ⚠️ 短期放量可被主力对敲造假，但缩量相对真实。同一形态在不同位置意义不同（低位放量=建仓，高位放量=出货）

#### 策略4：布林带收口后突破 + RSI确认
- **核心逻辑**：波动率收缩后往往有大行情，双重确认降低误判
- **买入信号**：
  - 布林带宽度收窄到近期最小（缩口）
  - 股价向上突破上轨
  - 成交量放大确认
  - RSI < 70（未极端超买时突破更可靠）
- **卖出信号**：
  - 股价跌回中轨以下
  - 或股价触及上轨 + RSI > 70 + KDJ超买死叉（三重确认卖出）
- **沿轨运行**：强势股会沿上轨持续运行，回踩中轨不破即为加仓点
- **适用**：盘整后的方向选择
- ⚠️ 布林带只告诉可能突破，不告诉方向。缩口时不宜提前建仓，需等方向确认

### 三、市场情绪指标参考

| 指标 | 看多 | 看空 |
|------|------|------|
| 涨跌比 | 上涨家数 > 70% | 下跌家数 > 70% |

### 四、A股市场特有规律

1. **政策市**：政策对行情有显著引导作用（降准降息、产业政策、监管政策），重大政策发布后优先关注受益板块
2. **板块轮动**：热点板块轮番炒作，资金在不同板块间切换，"炒新不炒旧"
3. **涨跌停磁力效应**：股价接近涨/跌停时，自我实现预期加速触及。涨停限制当日卖盘释放，未满足买盘延续到次日
4. **大资金行为**：大资金倾向于在涨停日买入、次日卖出；散户则相反
5. **散户占比高**：市场投机性强、情绪波动大，容易过度反应→短期反转因子有效
6. **日历效应**：重大节假日前资金偏谨慎，节后可能开门红或补跌；两会行情/年报行情有规律性
7. **北向资金**：被视为"聪明钱"风向标，但并非总是对的，需结合其他指标

### 五、风险管理规则

1. **仓位管理**：
   - 强势市场（主升期）：可满仓两只
   - 震荡市场（启动/分歧期）：半仓操作
   - 弱势市场（退潮期）：轻仓或空仓等待

2. **买入纪律**：
   - 不追高（涨幅 > 7% 不追）
   - 不在大盘暴跌日买入
   - 每次买入都要有明确的技术信号支撑
   - A股T+1：优先尾盘（14:50后）买入，缩短风险窗口

3. **卖出纪律**：
   - 买入逻辑被打破时卖出
   - 连续2天弱于大盘时考虑卖出
   - **动态止盈**：随价格上涨逐步提高止损位（如从成本价→+5%→+10%）
   - **技术止盈**：触及布林带上轨/前高阻力位时分批止盈
   - **固定止损**：亏损7-8%无条件止损（CANSLIM铁律）

4. **操作次数控制**：
   - 每日操作总次数最好不超过4次（买入和卖出各算1次）
   - 超过4次需反思是否过度频繁交易，避免手续费损耗和情绪化操作

5. **每日检查清单**：
   - [ ] 大盘趋势（上证指数 MA5/MA10/MA20 位置关系）
   - [ ] 市场情绪（涨跌比、涨停数、炸板率、连板高度）
   - [ ] 情绪周期判断（启动/主升/分歧/退潮？）
   - [ ] 持仓个股技术面（是否破位、量价是否健康）
   - [ ] 有无更好的标的可以换仓
   - [ ] 北向资金流向

### 六、量化因子参考（学术验证有效）

| 因子 | A股年化收益 | 稳定性 | 关键发现 |
|------|-----------|--------|---------|
| 规模因子(小市值) | ~20% | 高 | A股最稳健因子之一，2017后有所衰减 |
| 短期反转 | ~18.7% | 中 | A股散户多→短期过度反应，月胜率65% |
| 低波因子 | ~10% | 高 | 低波动股票收益反而更高 |
| 价值因子(低PE/PB) | 中等 | 中高 | 熊市末期/震荡市效果更好，需防价值陷阱 |
| 换手率 | 中等 | 中 | 对情绪敏感性最高，低换手率优于高换手率 |
| 动量因子 | 弱(分化) | 低 | **大盘股动量有效，小盘股反转有效** |

**重要结论**：单一因子不如多因子组合稳健。近期表现好的因子短期继续有效（因子动量）。

### 七、形态选股——找"形态好"的票

> 核心思路：好的形态 = 主力已经完成吸筹 + 即将启动。形态比指标更重要，指标是形态的数学抽象。

#### 看涨形态（优先选入）

| 形态 | 特征 | 买入时机 | 可靠性 |
|------|------|---------|--------|
| **杯柄形态** | U型底+小幅回调（柄），量先缩后放 | 放量突破柄的高点 | ⭐⭐⭐⭐⭐ |
| **W底（双底）** | 两次探底位置接近，第二底量萎缩 | 放量突破颈线位 | ⭐⭐⭐⭐ |
| **上升三角形** | 多次触碰同一高点，低点逐步抬高 | 放量突破水平阻力线 | ⭐⭐⭐⭐ |
| **底部放量长阳** | 长期横盘/下跌后突然放量涨>5% | 当日或次日回踩不破半分位 | ⭐⭐⭐⭐ |
| **箱体突破** | 区间内反复震荡后放量突破上沿 | 突破箱体上沿 | ⭐⭐⭐⭐ |
| **旗形整理** | 快速拉升后缩量沿下倾通道整理 | 放量突破旗面上轨 | ⭐⭐⭐ |
| **缩量回踩均线** | 上涨中缩量回调至MA10/MA20企稳 | 均线附近止跌企稳时 | ⭐⭐⭐ |

#### 看跌形态（回避或卖出）

| 形态 | 特征 | 操作 |
|------|------|------|
| **M顶（双顶）** | 两次冲高位置接近，第二顶量不足 | 跌破颈线卖出 |
| **头肩顶** | 左肩-头-右肩，右肩量<左肩 | 跌破颈线卖出 |
| **下降三角形** | 低点水平，高点逐降 | 回避 |
| **高位十字星** | 连涨后十字星，多空分歧 | 次日低开则卖出 |
| **断头铡刀** | 大阴线同时跌破MA5/10/20 | 立即卖出 |

#### "形态好"的综合标准
```
[必须] 底部形态完整（至少一种看涨形态）
[必须] 均线多头排列或即将形成
[必须] 近期缩量整理充分（筹码集中）
[加分] 即将或刚突破关键位（前高/颈线/箱体上沿）
[加分] 突破时放量确认
[加分] 位置不在高位（距低点涨幅<30-40%）
```

### 八、综合选股流程（每日执行）

```
第一步：宏观过滤
  └─ 大盘趋势向上？情绪周期在启动/主升期？
  └─ 否 → 空仓等待
  └─ 是 → 进入第二步

第二步：板块选择
  └─ 当日资金流入最多的行业/概念板块
  └─ 北向资金重点买入的板块
  └─ 政策利好驱动的板块

第三步：个股筛选
  └─ 板块内涨幅靠前、量比>2的个股
  └─ 排除ST、科创、创业板
  └─ 均线多头排列 + 技术指标共振

第三步半：形态筛选（关键！）
  └─ 是否有完整的看涨形态？（杯柄/W底/三角形/箱体突破等）
  └─ 是否缩量整理充分？
  └─ 是否在关键突破位附近？
  └─ 没有好形态的票不做！

第四步：技术 + 资金确认
  └─ MACD/KDJ/RSI/布林带至少2个指标给出买入信号
  └─ 量价关系健康（放量上涨、缩量回调）
  └─ 资金流向验证：
     • 当日主力净流入为正
     • 3日累计主力净流入为正（短期确认）
     • 5日累计主力净流入为正（中期确认，加分项）
     • 板块3-5日累计资金净流入靠前（主线确认）

第五步：决策执行
  └─ 确定仓位（根据市场情绪和已有持仓）
  └─ 确定挂单价（支撑位附近买入）
  └─ 设定止损位（-7%或关键均线下方）
```
