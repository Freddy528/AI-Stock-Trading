### 你需要什么
- 一台 Mac（本文基于 macOS）
- 安装了 Homebrew（macOS 包管理器）
- Claude Code（AI 编程助手）

### 实际交互
> 💬 **我**: 帮我配置下 git 吧，我的邮箱是 zz19970528@gmail.com
> 🤖 **AI**: 好的，配置 git 用户名和邮箱，生成 SSH Key...

**关键步骤：**
```bash
# 配置 git 身份信息
git config --global user.email "your-email@gmail.com"
git config --global user.name "your-name"

# 生成 SSH Key 用于连接 GitHub
ssh-keygen -t ed25519 -C "your-email@gmail.com"

# 复制公钥，粘贴到 GitHub Settings → SSH Keys
cat ~/.ssh/id_ed25519.pub
```

### 要点
- SSH Key 是你电脑和 GitHub 之间的"身份证"
- 生成后需要把公钥添加到 GitHub 网站上

## Step 2: GitHub 配置

### 安装 GitHub CLI
```bash
brew install gh
gh auth login --git-protocol ssh --web
```

### GitHub 核心概念速记
| 术语 | 含义 | 类比 |
|------|------|------|
| clone | 下载项目到本地 | 从网盘下载 |
| push | 上传改动到云端 | 同步到网盘 |
| pull | 下载云端最新改动 | 拉取最新版 |
| commit | 保存一个存档点 | 游戏存档 |
| PR | 请求合并代码 | 提交审核 |
| fork | 复制别人项目到自己账户 | 拷贝副本 |

### 邀请协作者
```bash
gh api repos/你的用户名/项目名/collaborators/对方用户名 -X PUT
```

## Step 4: 数据源接入

### 选择 AKShare
- 开源免费，无需注册
- 覆盖全部 A 股实时行情、历史 K 线、资金流向等

### 安装
```bash
pip3 install akshare
```

### 核心用法
```python
import akshare as ak

# 全部 A 股实时行情
df = ak.stock_zh_a_spot_em()

# 个股历史 K 线
df = ak.stock_zh_a_hist(symbol="000001", period="daily", start_date="20240101")

# 板块资金流向
df = ak.stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")
```

## Step 5: 系统架构搭建

### 核心模块

**1. config.py — 交易规则配置**
- 初始资金、最大持仓数、单股仓位上限
- 选股范围（排除ST/科创/创业板）
- 交易风格（激进型）

**2. account.py — 模拟账户**
- 买入/卖出（含佣金、印花税计算）
- 每日净值快照
- 交易历史记录

**3. data_fetcher.py — 数据获取**
- 实时行情、历史K线
- 技术指标计算（MA/MACD/KDJ/RSI/布林带）
- 市场情绪指标、资金流向

## 💡 给后来者的建议

1. **不需要会编程** — Vibe Coding 的核心是清晰表达需求，让 AI 写代码
2. **先模拟再实盘** — 至少模拟跑一段时间，验证策略有效性
3. **保持记录** — 每次交易都记录原因和结果，这是迭代的基础
4. **控制风险** — 再好的策略也会亏钱，关键是控制亏损幅度
5. **持续迭代** — 没有一劳永逸的策略，市场在变，策略也要变
