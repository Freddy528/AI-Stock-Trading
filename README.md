# 🤖💰 AI-Stock-Trading — AI炒股赚大钱

> AI 驱动的股票交易策略研究与实践项目

## 📌 项目简介

本项目旨在利用 AI 技术探索股票交易策略，包括但不限于：

- 📊 市场数据分析与可视化
- 🧠 AI 选股 / 择时策略研发
- 📈 回测系统搭建
- 🤖 自动化交易信号生成
- 📝 交易日志与策略复盘
